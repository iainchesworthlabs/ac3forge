# Generated

The image files here (`iclforge.ico`, `iclforge.icns`, `iclforge-32.png` and `iclforge-256.png`)
are generated by [`assets/icon/generate_icons.py`](../../../assets/icon/generate_icons.py) from one
procedural mark. Don't hand-edit one — change the drawing code in that script and re-run it
(`python assets/icon/generate_icons.py`, which needs Pillow). The same run writes the Android
launcher icons and banner and the WASM demo's `favicon-32.png` from that mark.

| File | Used for |
| --- | --- |
| `iclforge.ico` | The Windows executable's icon, through the `forge-gui.rc` the build generates from `forge-gui.rc.in`. |
| `iclforge.icns` | The macOS bundle's icon. |
| `iclforge-32.png`, `iclforge-256.png` | The window icon (`main.cpp`) and the About dialog, embedded as the `forge_gui_icons` resource. On Linux the package also installs them as `forge-gui.png` in the hicolor `32x32` and `256x256` directories. |

`forge-gui.rc.in` is the one hand-authored file beside them: a template for the Windows resource
script, not generated by that script. The build turns it into `forge-gui.rc` in the build tree with
the `.ico`'s absolute path filled in.
