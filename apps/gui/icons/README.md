# Generated

The image files here (`ac3forge.ico`, `ac3forge.icns`, `ac3forge-32.png` and `ac3forge-256.png`)
are generated by [`assets/icon/generate_icons.py`](../../../assets/icon/generate_icons.py) from one
procedural mark. Don't hand-edit one — change the drawing code in that script and re-run it
(`python assets/icon/generate_icons.py`, which needs Pillow). The same run writes the Android
launcher icons and banner and the WASM demo's `favicon-32.png` from that mark.

| File | Used for |
| --- | --- |
| `ac3forge.ico` | The Windows executable's icon, through the `ac3gui.rc` the build generates from `ac3gui.rc.in`. |
| `ac3forge.icns` | The macOS bundle's icon. |
| `ac3forge-32.png`, `ac3forge-256.png` | The window icon (`main.cpp`) and the About dialog, embedded as the `ac3gui_icons` resource. On Linux the package also installs them as `ac3gui.png` in the hicolor `32x32` and `256x256` directories. |

`ac3gui.rc.in` is the one hand-authored file beside them: a template for the Windows resource
script, not generated by that script. The build turns it into `ac3gui.rc` in the build tree with
the `.ico`'s absolute path filled in.
