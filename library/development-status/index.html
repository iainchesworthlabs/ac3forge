    Development status¶

    At-a-glance implementation status for every codec, coding tool, metadata field, and related bitstream surface this repository owns — the companion to Capabilities and limitations.

    Page Role
    This page Status of each feature: done, partial, or not started
    Capabilities What each shipped feature does, with the spec sections and the limitations that shape use
    Validation How claims are checked, and where external oracles do not reach
    Roadmap Candidate work and history behind stable IDs (IM5, EQ10, …)
    Application coverage Which applications expose each broad library capability

    CONTRIBUTING.md still makes Capabilities and Validation the authority when a capability lands or a limitation is found. Update those first; refresh the matching row here so the status table stays a summary rather than a second capability record.

    Legend: 🟢 Completed • 🟡 Partial / in progress • 🔴 Not started / refused / out of scope

    Statuses describe the bitstream and API surface, not application polish. A green row can still carry a note about an oracle gap, an intentional auto exclusion, or an interoperability caveat — those details live in Capabilities and Validation.

    The tables below were cross-checked against the cited standards (A/52 / TS 102 366 including Annexes D–H and F, TS 103 420, TS 103 190-1/-2, ST 2098-2, BS.2076 / BS.2088, IAMF v1.1.0, and the carriage specs wired in-tree). Open gaps against those texts are collected again under Standards cross-check.

    How to read a yellow or red row¶

    • 🟡 Partial means the feature exists with a documented bound (parser narrower than commercial streams, syntax without PCM, branch not merged, intentional auto exclusion called out elsewhere). The bound is the note; the prose is in Capabilities.
    • 🔴 Not started / refused / out of scope means no implementation on main for that specification surface, or an explicit refuse. Roadmap IDs in the notes point at Roadmap where one exists.
    • Oracle and hardware gaps are not red features by themselves. A completed encoder whose only external decoder is this project's own is still 🟢, with the gap recorded under Validation and noted in the standards register where useful.
