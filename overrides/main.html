AC‑3 · E‑AC‑3 · Dolby Atmos

AC3Forge

A clean-room AC-3, E-AC-3 and Dolby Atmos codec, written from the published standards in C++23 — Library — and the two applications built on it: Forge, the CLI and GUI, and Crucible, a desktop per-application Atmos mixer.

ac3::forge

Library

Encodes and decodes AC-3 and E-AC-3, including Atmos objects via Joint Object Coding. C++23, with C, Python, Rust and WebAssembly bindings.

Read the library docs → ac3cli · ac3gui

Forge

ac3cli and ac3gui are one product: they build together, ship together, and the GUI shows the equivalent CLI command live at the bottom of its window.

Read the Forge docs → desktop app

Crucible

Every application on your desktop becomes an object in an Atmos scene — drag one into position, and what leaves for your receiver follows your hardware. Windows and Linux run it; the macOS half compiles but has never been launched.

Read the Crucible docs →
