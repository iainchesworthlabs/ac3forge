# mypy stubtest allowlist for the iclforge wheel (wheels.yml's stubtest step).
#
# The stub represents each runtime submodule (m.def_submodule) as a class -
# the convention every submodule's own .pyi comment states, and the shape
# pybind11-stubgen emits too - so stubtest sees a class in the stub where the
# runtime has a module. These entries allow exactly that shape difference;
# the CONTENTS of each namespace are still checked member by member.
iclforge\.(ac4|eac3|meta|signing|containers|verify)
# pybind11 enums expose __members__/__int__/__index__ from their own enum
# machinery; the stubs model them as enum.Enum, which spells the members but
# not pybind11's dunder surface.
iclforge\.(Acmod|CentreMixLevel|DecodeError|FrameError|ProfileId|SampleRate|ScanError|StreamKind|StreamType|SurroundMixLevel)\.__(members|int|index)__
# type(X) is pybind11's own metaclass at runtime, which a stub cannot spell.
# These entries are ANCHORED CLASS NAMES, so they allow only class-level
# complaints (the metaclass one); attribute errors carry the attribute's own
# dotted name and are still reported.
iclforge\.(AccessUnitTiming|AtmosConfig|AtmosEncoder|DecodedAccessUnit|DecodedFrame|DecodedProgram|DecodedSubstream|DecoderConfig|DynamicObject|Eac3Decoder|EncoderConfig|FrameDecoder|FrameEncoder|FrameHeader|HeavyConfig|LatencyBudget|ObjectPlacement|Position|Profile|Program|ScannedProgramme|ScannedStream|SubstreamService)
# ac3.ac4's own enums/classes need no metaclass/dunder allowance here - unlike
# the top-level entries above, stubtest reports a clean match against this
# submodule's stub without one (confirmed empirically: adding the equivalent
# iclforge\.ac4\.* entries made stubtest fail on "unused allowlist entry").
# KwargBinder constructors take **kwargs at runtime; the stubs for the plain
# config classes spell the fields instead. Same convention as the C++ side's
# designated initializers.
iclforge\..*\.__init__
